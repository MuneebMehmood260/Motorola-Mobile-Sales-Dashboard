# 📖 Overview

The **Motorola Mobile Sales Dashboard** is an interactive Business Intelligence solution built using **Microsoft Power BI**. It provides valuable insights into Motorola mobile sales performance by analyzing revenue, quantity sold, customer purchasing behavior, regional performance, and product trends.

This was my **first Power BI project**, where I learned to transform raw data into meaningful business insights using Power BI, Power Query, and DAX.

---

# 🎯 Objectives

- Analyze overall mobile sales performance.
- Monitor revenue and quantity sold.
- Compare regional sales.
- Identify top-performing products.
- Track monthly sales trends.
- Build an interactive dashboard for business decision-making.

